# 🏋️ AI Fitness Form Analyzer

A real-time computer vision system that tracks exercise form and counts repetitions using pose estimation.  
Built using OpenCV and MediaPipe, this project analyzes body movements to provide live feedback for multiple exercises.

---

## 🚀 Features

- 🧠 Real-time pose detection using MediaPipe
- 🏋️ Exercise tracking:
  - Squats
  - Pushups
  - Bicep Curls
- 🔄 Left vs Right arm curl tracking
- 🏋️‍♂️ Basic weight/dumbbell detection near wrists
- 📊 Automatic rep counting
- ⚠️ Live posture feedback
- 📝 Workout logging to CSV
- 📈 Interactive dashboard (Streamlit)
